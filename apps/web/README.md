# BuildingOps AI — web

Next.js app: the interface, the sign-in flow and the authenticated proxy to the API. Setup
and conventions are in the repository's `README.md` and `docs/development.md`.

```bash
pnpm install
pnpm dev        # http://localhost:3000 (the API must be running on :8000)
pnpm test       # unit and component tests
pnpm e2e        # end-to-end tests in a real browser
```
